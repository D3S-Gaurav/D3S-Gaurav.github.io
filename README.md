# Kumar Gaurav: the arcade portfolio

A single-level retro maze game where the visitor plays my career. Built with Vite, TypeScript and Canvas 2D, and hosted on GitHub Pages.

```bash
npm install
npm run dev     # local development
npm run build   # type-check and build to dist/
```

All story text lives in `content/content.json`, so updating the portfolio never means editing game code. The plain resume at `/#resume` is generated from the same file at build time.
